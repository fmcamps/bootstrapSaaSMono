## Cambios en fmcamps.css

### 1. Migracion app1.css → SCSS partials

Todas las reglas genericas que estaban en `app1.css` fueron migradas a 31 archivos SCSS parciales en `scss/fmcamps/`. El CSS compilado (`fmcamps.css`) ahora contiene todo lo que antes estaba repartido entre ambos archivos.

`app1.css` quedo reducido a solo reglas que **requieren** estar ahi: cursores custom (`image-set()`), logos (`content: url()`), view-transitions, selectores de ID (`#grilla_stock`, `#overview`, `#logopk`), bootbox modal.

### 2. Limpieza de !important (36 eliminados en 3 rondas)

- Ronda 1: 3 removidos (vendor prefixes)
- Ronda 2: 24 removidos (overrides de Bootstrap que no los necesitaban)
- Ronda 3: 9 removidos
- Quedan 71, todos justificados (37 third-party, 10 dark-theme, 9 layout, 6 utilities, 7 specificity, 2 dynamic)
- Verificado con 48 tests de regresion visual Playwright (12 paginas x desktop/mobile x light/dark)

### 3. Fallbacks light-dark() (89 instancias, todas con fallback)

- Agregados 64 fallbacks estaticos que faltaban
- Patron: linea con valor fijo (light) antes de la linea `light-dark()`
- Protege browsers intermedios (Chrome 60-122, Safari 12-17.4) que soportan `var()` pero no `light-dark()`
- Estos browsers ven siempre tema claro; dark mode no funciona pero nada se rompe

### 4. Bugs de sintaxis corregidos

- `_typography.scss`: `light-dark(var(--light-color) #21211f, ...)` — faltaba coma
- `_dropdowns.scss`: `light-dark(var(--light-color),)` — segundo argumento vacio

### 5. Vendor prefixes removidos (~50)

Autoprefixer con browserslist actualizado elimino prefijos `-webkit-`, `-moz-` que
ya no son necesarios: `appearance`, `user-select`, `text-decoration-skip-ink`,
`print-color-adjust`, `transition`, entre otros.

### 6. Browserslist actualizado

- Eliminado IE 10/11 (nunca funciono con `var()`, el sitio ya estaba roto)
- Nuevo minimo: Chrome 60+, Firefox 60+, Edge 79+, Safari 12+

### 7. Migracion dart-sass

- Pipeline CSS migrado de `node-sass` a `sass` (dart-sass)
- Elimina restriccion de Node 18 LTS
- Salida CSS puede tener diferencias menores de formato (espacios, orden de propiedades)

### 8. Cambios pendientes (sin commitear aun)

- `_forms.scss`: width/height del custom switch movidos al selector correcto
  (`.custom-switch .custom-control-label::before` en vez de estar duplicados en selectores genericos)
- `_alerts.scss`: `.alert .close` con `border: 0; outline: 0;` para el boton de cerrar alertas
